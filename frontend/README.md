# MedCare IoT Frontend

Frontend React/Vite preservado a partir do projeto do AI Studio e conectado ao backend Express.

## Rodar

```bash
npm install
copy .env.example .env
npm run dev
```

No Linux/macOS:

```bash
cp .env.example .env
npm run dev
```

URL padrão:

```txt
http://localhost:3000
```

## Variável de ambiente

```txt
VITE_API_URL=http://localhost:3001
```
